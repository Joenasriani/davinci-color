# DaVinci Resolve Color Page — Student Reference Guide

Live guide: https://joenasriani.github.io/davinci-color/

This repository contains an instructor-authored visual reference for students learning selected tools on the DaVinci Resolve Color page. It pairs screenshots with concise explanations of what each panel does, when it is useful, and what limits students should keep in mind.

## Covered panels

- Primaries / Color Wheels
- HDR Wheels
- Custom Curves
- ColorSlice
- RGB Mixer
- Color Match
- Camera Raw
- Motion Effects

## Version and scope

The teaching text was audited against Blackmagic Design's DaVinci Resolve 20 Colorist Guide and current Color-page documentation on 2026-09-17. The screenshots in this repository were captured in 2025, so labels, layout, available controls, and edition-specific features may differ in other Resolve versions, platforms, media formats, or project color-management configurations.

This is a focused reference, not a replacement for the full DaVinci Resolve manual or Blackmagic Design training curriculum.

## Important boundaries

- Workflow examples are examples, not mandatory grading orders.
- Color-management settings determine how several controls should be interpreted and configured.
- Camera Raw controls depend on the source RAW format and project configuration.
- Chart-based Color Match is a starting/calibration tool, not a guarantee that two shots or cameras will match perfectly.
- Temporal and spatial noise reduction in the Motion Effects palette require DaVinci Resolve Studio.
