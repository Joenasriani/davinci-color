DaVinci Resolve Color Page — Student Reference Guide

Use the tabs to review selected Color page tools, what they change, when they are useful, and the limits of each method.

Content audited against Blackmagic Design's DaVinci Resolve 20 training material on 17 September 2026. Screenshots were captured in 2025. Interface labels, feature availability, RAW controls and color-management behavior can vary by Resolve version, platform, media format and Free/Studio edition.

1. Primaries — Color Wheels

What it does

The Primary Wheels make broad color and tonal adjustments using overlapping ranges: Lift for darker tones, Gamma for midtones, Gain for brighter tones, and Offset for the image as a whole.

When it is useful

Use Primaries for image balancing and broad corrections such as exposure, color balance, contrast and saturation. They are commonly used early in a grade, but there is no single mandatory node order for every project.

Key controls

  • Lift: changes darker tonal regions, with overlap into adjacent tones.
  • Gamma: changes midtone regions, with overlap into darker and brighter tones.
  • Gain: changes brighter tonal regions, with overlap into adjacent tones.
  • Offset: changes the image globally rather than targeting one tonal range.
  • Temperature and Tint: shift the overall color balance along warm/cool and green/magenta axes.
  • Contrast and Pivot: alter tonal separation and the tonal center around which contrast is applied.
  • Saturation: changes overall color intensity.
  • Color Boost: increases saturation more strongly in areas that begin with lower saturation.
Practice: balance a shot while watching the image and scopes. Do not treat fixed black-point, white-point or skin-tone values as universal rules; target levels depend on the source, color-management pipeline and deliverable.

2. HDR Wheels

What it does

The HDR palette provides color and exposure controls mapped to customizable tonal zones. Those zones can be moved or resized to suit the tonal structure of the shot.

When it is useful

Use it when you want more direct control over a selected tonal region than broad Primary adjustments provide, especially across wide dynamic ranges.

Key controls and limits

  • Zone wheels: target defined tonal regions such as dark, shadow, light or additional custom zones.
  • Zone-range controls: change where each tonal zone operates and how it transitions into neighboring ranges.
  • Exposure and color controls: modify the selected range rather than mathematically isolating it from all other tones.
  • Global: applies a broader image-wide adjustment.
Practice: target a bright sky with a lighter HDR zone, then watch the rest of the image while adjusting it. HDR zones have transitions and overlap; do not assume an adjacent face or object will remain completely unchanged.

3. Custom Curves

What it does

Custom Curves map input tonal or channel values to new output values. Control points let you reshape that relationship instead of applying one global contrast or color adjustment.

When it is useful

Use curves for localized tonal shaping or for controlled changes to individual RGB channels. An S-shaped curve is one possible contrast treatment, not a required grading style.

Reading the graph

  • The horizontal axis represents input values; the vertical axis represents output values.
  • Moving a point upward raises that mapped output value; moving it downward lowers it.
  • Channel selectors let you work on combined tonal response or individual RGB channels, depending on the selected curve mode.
Practice: make a small curve adjustment and compare it with the ungraded image and scopes. Avoid assuming that more contrast is automatically a better result.

4. ColorSlice

What it does

ColorSlice provides predefined, adjustable color vectors such as Red, Skin, Yellow, Green, Cyan, Blue and Magenta. The ranges are blended rather than being hard masks.

When it is useful

Use it to reshape selected hue families without building a separate Qualifier selection for every adjustment. Neighboring hues can still be affected, so the result must be inspected.

Key controls

  • Vector/Color control: changes the selected color family.
  • Center: repositions the center of the affected hue range.
  • Density: changes luminance and saturation together. In Blackmagic's current Colorist Guide, raising Density produces darker, more saturated color.
  • Saturation: changes saturation using ColorSlice's subtractive model, with stronger influence in midtones and shadows than highlights.
Practice: select the Blue vector, use the highlight/range view if available, adjust Center only if the intended blues are not covered, then make small Density or Saturation changes. Check nearby cyan, skin and neutral regions for spill.

5. RGB Mixer

What it does

The RGB Mixer changes how much of the source red, green and blue channels contribute to each output channel.

When it is useful

Use it for channel remapping, controlled color casts, technical channel experiments and monochrome conversions where you want to determine how the original channels contribute to the result.

Key controls and limits

  • Output columns: define the composition of the resulting red, green and blue channels.
  • R/G/B contribution sliders: determine how much of each source channel is mixed into the selected output channel.
  • Monochrome: creates a black-and-white result whose tonal contribution can be shaped by the channel mix.
  • Luminance/normalization options: can constrain the relationship between channel mixing and overall brightness, but the result should still be checked visually and on scopes.
Practice: enable Monochrome and vary the source-channel contributions while watching how colored objects convert to gray. This makes the effect of channel mixing easier to see than memorizing arbitrary RGB values.

6. Color Match

What it does

Color Match uses a supported color chart visible in the recorded image and compares sampled patches with known chart targets to create an automatic correction.

When it is useful

Use it when a properly exposed and aligned supported chart was recorded under the scene lighting. It can provide a useful calibration or starting point before manual balancing and shot matching.

Correct setup

  1. Choose the chart type that actually appears in the footage.
  2. Align the on-screen chart grid carefully with the recorded patches.
  3. Set Source Gamma, Target Gamma and Target Color Space to match the project's real color-management path. These values are not universally Rec.709.
  4. Click Match, then inspect the result on scopes and against the other shots.
Limit: Color Match does not guarantee a 100% neutral image or perfect camera-to-camera matching. Chart exposure, lighting, reflections, alignment, camera response and color-management settings all affect the result.

7. Camera Raw

What it does

The Camera Raw palette exposes decoder controls for supported RAW media. Available parameters depend on the RAW format, camera metadata and project color-management configuration.

When it is useful

Use it when a RAW clip needs source-specific decode adjustments such as ISO, exposure or white-balance interpretation before normal node-based grading.

Important distinctions

  • Decode Using: Camera/Project/Clip choices determine whether metadata, project defaults or per-clip overrides are used. Clip is useful when you need a per-clip override; it is not a universal requirement.
  • RAW controls: ISO, Exposure, Color Temperature, Tint, Highlight Recovery and other controls vary by codec and camera.
  • Color management: some Raw palette color-space and gamma controls can be disabled or interpreted differently in color-managed projects.
Limit: changing RAW decoder metadata after recording is not the same as changing the physical exposure at capture time. RAW processing can use recorded sensor data more flexibly than many encoded formats, but it cannot recover information that was never recorded or that is genuinely clipped.

8. Motion Effects

What it does

The Motion Effects palette contains temporal and spatial noise-reduction controls plus motion-blur controls. Temporal NR compares information across frames; Spatial NR works within a frame.

Availability

Blackmagic documents temporal noise reduction, spatial noise reduction and Motion Effects as DaVinci Resolve Studio features. Students using the free edition may not have these controls.

Working method

  1. Evaluate whether the shot actually needs noise reduction before enabling it.
  2. Blackmagic's current Color-page guidance recommends starting with temporal reduction and adding spatial reduction gradually if needed.
  3. Use conservative thresholds and review moving detail as well as still frames.
  4. Watch for ghosting, smearing, texture loss and excessive render/playback cost.
Workflow note: node placement depends on the grade and pipeline. Do not memorize “always first” or “always last” placement as a universal rule.
